# 🔋 Battery Defect Locator: 基于因果推断与 SHAP 的电池制程缺陷定位框架

## 📖 项目背景
在锂离子电池制造（如前段涂布、辊压，后段注液、化成）中，传统基于统计过程控制（SPC）或单变量分析的方法难以识别**“工序协同效应”**导致的良率波动（例如：压实密度偏上限 + 注液量偏下限，两者均未超差，但协同导致局部析锂）。

本项目旨在探索一种数据驱动方法，通过结合**树模型 (LightGBM)**、**特征归因 (SHAP)** 与 **因果推断 (gCastle)**，实现复杂非线性制程数据的“根因定位”与“物理传导链还原”。

## ✨ 核心亮点
1. **中间变量陷阱**：强制剥离化成内阻等中间测试项，逼迫模型寻找真正的工艺源头参数。
2. **多重系统熔断防呆**：内置样本维度安检（N/P Ratio）、方差检验与模型 R² 置信度检验，拒绝“瞎报警”。
3. **从相关到因果**：不仅通过 SHAP 提取帕累托主因，更利用 Notears 算法还原物理传导有向无环图（DAG），为工程师提供切实可行的调参指南。

## ⚙️ 如何运行 (Quick Start)
本项目数据为基于电池物理化学机理生成的 **Mock Data（虚拟脱敏数据）**，不包含任何企业真实产线数据，仅作算法框架验证使用。

```bash
# 安装依赖
pip install -r requirements.txt

# 运行分析脚本
python main.py
```
